## Four Beats

1. **Name the plant.** Give the CADISON project database a short title before you draw a line.
2. **Pin the live tags.** Keep current equipment on CADISON plant engineering and leave archived lines aside.
3. **Check the sheets.** Read CADISON P&ID drawings before you move a 3D pipe.
4. **Close the loop.** Clear finished lines so the next CADISON visit does not start with a search.

## First Questions

**Does CADISON replace every other program?**
No. CADISON sits beside the viewer, browser, and files you already use.

**Can two people share one computer?**
Yes. Each person keeps a separate CADISON profile.

**What should a new user try first?**
One small CADISON P&ID today, then the same project database tomorrow.

## Who Sits Down at CADISON

- **Process** — equipment tags stay on the CADISON project database.
- **P&ID** — sheets stay attached to CADISON P&ID drawings.
- **Piping** — routes stay on CADISON 3D piping.
- **Shared desk** — each CADISON profile keeps its own pins.
- **Handoff** — the next person can read the CADISON note without a tour.

## Field Note

CADISON is easier to trust when the project database stays smaller than the folder it came from. A named plant shows what is active, the P&ID sheets show what you will touch today, and the closing note tells the next person which pipe changed.

## One Real Pass

Pick a plant that already has a name. Open it in CADISON, keep only those lines on the project database, and finish one P&ID sheet you can see.
